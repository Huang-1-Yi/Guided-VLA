## 口诀（先背这个，5 秒钟）

1. **这个仓库干一件事**：让 PI0/PI05 在多种机器人环境上能训练、能评估、能服务化推理。
2. **两条平行实现线**：`src/openpi/` (72 .py) 和 `src/padp/` (64 .py)，**PADP 单向借用 openpi 的 IO**。
3. **openpi 内部双实现**：JAX 版（继承原 openpi，14 个 .py） + PyTorch 版（当前实际训练用，6 个顶层 .py + 3 个子包）。**GuidedVLA 的所有「增强」都只加在 PyTorch 那边**。

把上面三句话默写两遍，再看下面。

## 小图 2 / 5 — 核心区放大（openpi vs PADP 的关系）

核心区里只有两个包，`src/openpi/` 和 `src/padp/`，它们**不是平行，而是单向借用**：

```text
核心区
  │
  ├── src/openpi/        72 个 .py      ← 你日常要改的 90% 都在这
  │     │
  │     ├── training/        (配置 + 数据加载 + checkpoint + optimizer)
  │     │     ★ config.py            -- TrainConfig / DataConfig
  │     │     ★ data_loader.py       -- LeRobot → Observation
  │     │
  │     ├── policies/        (环境字段适配，5 个 env + 1 个 oxe)
  │     │     ★ libero_policy.py     -- LiberoInputs（先看这个）
  │     │
  │     ├── models/          (JAX/NNX 版，继承自 openpi)
  │     │     pi0.py / pi0_config.py / gemma.py / siglip.py / tokenizer.py / lora.py ...
  │     │
  │     ├── models_pytorch/  (PyTorch 版，★ GuidedVLA 实际训练走这条)
  │     │     pi0_pytorch.py / gemma_pytorch.py / control_attention.py
  │     │     attention/attn_paths.py
  │     │     depth/{model, depth_attention, token_merging}.py
  │     │
  │     ├── transforms.py    (数据变换管道)
  │     ├── serving/         (websocket 推理服务)
  │     └── shared/          (工具：normalize / download / array_typing ...)
  │
  └── src/padp/          64 个 .py      ← 独立实现，复用 openpi 的 IO
        │
        ├── config/ data/ dataset/   ← 借 openpi 的（DataConfig, data_loader, tokenizer）
        ├── model/                   ← 自己重写（diffusion UNet + DINOv3 vision）
        ├── policy/ workspace/ training/   ← 自己重写训练主循环
        └── serving/ common/
```

**最关键的一条箭头**（验证过，代码里真实存在）：

```text
src/padp/  ──imports──▶  src/openpi/training/data_loader
                       src/openpi/training/config
                       src/openpi/models/tokenizer
                       openpi_client

反方向（src/openpi/import padp）  ← 不存在
```

记忆点：**PADP 不是把 openpi 推倒重来**，是「**数据 IO + tokenizer 借 openpi 的，模型和训练自己写**」。

## 小图 3 / 5 — GuidedVLA 相对原 openpi 的「三大增强」

你只要知道原 openpi 仓库长什么样，再加这三块就是 GuidedVLA：

```text
src/openpi/models_pytorch/  (GuidedVLA 实际训练的主线)
  │
  ├── 基础（继承自 openpi）
  │     pi0_pytorch.py         PI0/PI05 主模型
  │     gemma_pytorch.py       PaliGemma + action expert
  │     preprocessing_pytorch.py
  │
  └── ★ 三大增强（GuidedVLA 多出来的）
        │
        ├── 增强 1：control_attention.py
        │     ControlNet 风格双分支 attention
        │     origin branch + control branch + zero_conv 融合
        │
        ├── 增强 2：attention/attn_paths.py
        │     attention head 路由
        │     把 head 分到 standard / object / depth 不同路径
        │
        └── 增强 3：depth/
              model.py          Depth Anything 3（视觉几何编码器）
              depth_attention.py   depth token 的 cross-attention
              token_merging.py     depth feature 合并成 token
```

**记忆口诀**：**「一双 (control) 一路 (attn_paths) 一深 (depth)」**。

| 增强 | 解决什么问题 | 看哪个文件最直接 |
|------|--------------|------------------|
| control_attention | 让模型同时学两种 attention 模式（原始 + 控制） | `control_attention.py` |
| attention/attn_paths | 让不同 attention head 走不同路径（标准/物体/深度） | `attention/attn_paths.py` |
| depth | 注入深度几何信息辅助决策 | `depth/model.py` |

## 小图 4 / 5 — 一条样本的「一生」

把整张图压成**最简单的一条链**——一条 LeRobot 样本从磁盘走完 9 站变成推理结果：

```text
[磁盘]  LeRobot 数据集
   │
   ▼  ① data_loader.py 读出来
[内存]  原始 dict {state, image, action, prompt, ...}
   │
   ▼  ② transforms.py 串一串变换（normalize / resize / tokenize / pad）
[内存]  统一字段（state_norm, image_norm, tokenized_prompt）
   │
   ▼  ③ policies/libero_policy.py 的 LiberoInputs
[内存]  Observation 对象（openpi 统一 schema：state, image, image_mask,
                          tokenized_prompt, tokenized_prompt_mask）
   │
   ▼  ④ pi0_pytorch.py 前向（flow matching）
[内存]  预测的 action + 辅助 head 输出（object / skill / depth）
   │
   ▼  ⑤ compute_loss (flow matching MSE + 辅助 loss 加权)
[标量]  loss
   │
   ▼  ⑥ optimizer.step() + DDP all-reduce
   │
   ▼  ⑦ checkpoints.py 落盘
[磁盘]  ckpt
   │
   ▼  ⑧ serve_policy.py 启动 websocket policy server
[进程]  websocket listener
   │
   ▼  ⑨ openpi-client 调 → examples/libero/main.py 跑仿真
```

**记忆口诀**：**「读-变-齐-前-损-优-存-服-调」9 个字**。

| 步骤 | 文件 | 课 |
|------|------|---|
| ① | `src/openpi/training/data_loader.py` | L2 |
| ② | `src/openpi/transforms.py` | L2 |
| ③ | `src/openpi/policies/libero_policy.py` | L3 |
| ④⑤ | `src/openpi/models_pytorch/pi0_pytorch.py` | L4 |
| ⑤ 加权 | `scripts/train_pytorch.py` | L7 |
| ⑥ | `src/openpi/training/optimizer.py` | (L7) |
| ⑦ | `src/openpi/training/checkpoints.py` | (L7) |
| ⑧⑨ | `scripts/serve_policy.py` + `openpi_client/websocket_client_policy.py` | L8 |

## 小图 5 / 5 — 「我要改 X 时，去看 Y」速查

这是最实用的一张——把「想做什么 → 改哪个文件」直接列出来：
